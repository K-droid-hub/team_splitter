# 概要
コマンド入力者が入室しているボイスチャット内のメンバーを複数チームに分けます。任意のチャンネルで `/` を入力すればサジェストが出てくるため、コマンドと付随するオプションを選択してください。

# コマンド一覧
オプションは全て任意であり、デフォルトの値が設けられています。オプションを指定しない場合、デフォルトの値が使用されます。

| コマンド             | オプション                                | 備考                                                             |
| ---------------- | ------------------------------------ | -------------------------------------------------------------- |
| /チーム数で分ける        | チーム数 (デフォルト: 2)                      |                                                                |
| /1 チームあたりの人数で分ける | 人数 (デフォルト: 5)                        |                                                                |
| /人数分抽選           | 人数 (デフォルト: 5) / 優先者 ( "," 区切りで複数指定可) | ここで追加する優先者は固定されません。                                            |
| /一覧表示             | --                                   | 固定されていないメンバーは `次だけ〇〇` と表記されます。                                 |
| /観戦者登録           | 固定 (デフォルト: しない)                | 観戦者はチーム分けに含まれません。固定しない場合、次のチーム分けが終わった後、観戦者から自動で解除されます。         |
| /観戦者解除           | --                                    | 観戦者を解除します。同時に複数人指定はできません。                                      |
| /優先者登録           | 固定 (デフォルト: しない)                | 優先者は、人数分抽選に必ず選ばれるようになります。固定しない場合、次のチーム分けが終わった後、優先者から自動で解除されます。 |
| /優先者解除           | --                                   | 優先者を解除します。同時に複数人指定はできません。                                      |
| /リセット             | --                                   | 観戦者と優先者を全員解除します。                                               |
| /読み上げ開始           | 入退室通知 (デフォルト: しない)               | bot が実行者のボイスチャットに参加し、コマンドを打ったテキストチャンネルの発言を読み上げます。入退室通知を on にすると入退室も読み上げます。 |
| /読み上げ終了           | --                                   | 読み上げを終了し、ボイスチャットから退出します。ボイスチャットが bot だけになると自動で退出します。 |
| /読み上げ声設定         | 話者 (必須)                            | あなたの発言を読み上げる声を選択します。未設定の人は既定の声で読み上げられます。 |
| /パネル               | --                                   | チャンネルに操作パネルを設置します。各コマンドをボタンから実行でき、スラッシュコマンドが苦手な人でも使えます。         |

# 読み上げ機能
`/読み上げ開始` で bot がボイスチャットに参加し、VOICEVOX で発言を音声合成して読み上げます。音声合成には別途 VOICEVOX エンジンが必要です(下記「運用」参照)。

`/読み上げ声設定` で選んだ声は SQLite (`data/voices.db`) に保存され、コンテナをリビルド・再起動しても保持されます。Docker Compose では `voice_data` という named volume に載せているため、`docker compose up --build` で作り直しても設定は消えません。保存先は `.env` の `VOICE_DB_PATH`(既定 `data/voices.db`)で変更できます。

# 操作パネル
`/パネル` を実行すると、そのチャンネルにボタン付きの操作パネルが設置されます。各機能はボタンから実行でき、チーム数・人数・対象メンバーといった入力もその場に出るボタンから選ぶだけです(スラッシュコマンドを覚える必要はありません)。パネルは操作のたびに最新の状態でチャンネル最下部へ貼り直されます。

# Bot 権限

## 一般権限
- チャンネルを表示
- メンバーを管理

## テキストの権限
- メッセージを送る
- メッセージ内容の取得
- 埋め込みリンク

## 音声の権限
- 接続
- 音声

# 運用
`.env-template` のファイル名を `.env` に修正し、DISCORD_TOKEN と GUILD_IDS を入力してください。特定のグループでしか動作しない仕様になっています。

## 読み上げのための追加準備
読み上げ機能には VOICEVOX エンジンと ffmpeg が必要です。

- Discord は 2026-03-02 に voice の DAVE(E2E 暗号化)を必須化したため、bot が voice に参加するには DAVE 対応版の discord.py(2.7 以降)と `davey` パッケージが必要です。どちらも `requirements.txt` に含めています(未対応版では close code 4017 で接続拒否されます)。
- `.env` の `VOICEVOX_URL`(既定 `http://voicevox:50021`)で VOICEVOX エンジンの接続先を、`VOICEVOX_SPEAKER`(既定 `3`)で既定話者を指定します。
- Docker Compose で起動する場合、`voicevox` サービスが自動で立ち上がり、ffmpeg も bot イメージに同梱されます。追加の準備は不要です。
- ローカルで直接実行する場合は、別途以下が必要です。
  - VOICEVOX エンジン: `docker run --rm -p 50021:50021 voicevox/voicevox_engine:cpu-latest`
  - ffmpeg: `brew install ffmpeg`(macOS の場合)
  - Python 依存: `pip install -r requirements.txt`(PyNaCl・davey を含む)
  - このとき `.env` の `VOICEVOX_URL` は `http://localhost:50021` にしてください。
